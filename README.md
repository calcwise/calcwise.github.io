# amortize.by

Бесплатные калькуляторы кредитов: ипотека (готово) и кооператив (в планах). График платежей
считается по банковской методике, поэтому итоги сходятся с расчётниками банков.

Статический сайт на Astro 7. Сборка — папка с файлами, сервера приложений нет.

## Что нужно

- Node 22.12+
- npm

## Запуск

```bash
npm ci
npm run dev        # http://localhost:4321
```

## Команды

| Команда           | Что делает                              |
| ----------------- | --------------------------------------- |
| `npm run dev`     | dev-сервер                              |
| `npm run build`   | сборка в `dist/`                        |
| `npm run preview` | отдать собранный `dist/`                |
| `npm run check`   | проверка типов и шаблонов               |
| `npm test`        | тесты расчётного ядра                   |
| `npm run lint`    | ESLint с автопочинкой                   |
| `npm run format`  | Prettier                                |
| `npm run icons`   | пересобрать иконки и OG-картинку из SVG |

Перед завершением задачи все четыре должны быть зелёными:

```bash
npm run build && npm run check && npm run lint && npm test
```

## Страницы

| Адрес                          | Что это                                              |
| ------------------------------ | ---------------------------------------------------- |
| `/`                            | главная: выбор раздела, живой пример графика         |
| `/mortgage/`                   | калькулятор ипотеки со всеми настройками             |
| `/mortgage/compare/`           | сравнение до трёх сценариев                          |
| `/mortgage/annuity/`           | аннуитетный график                                   |
| `/mortgage/differentiated/`    | дифференцированный график                            |
| `/mortgage/early-repayment/`   | досрочное погашение                                  |
| `/mortgage/grace-period/`      | отсрочка по основному долгу                          |
| `/mortgage/preferential-rate/` | льготная ставка на первые месяцы, ставка по периодам |
| `/guide/`                      | формулы и методика                                   |
| `/cooperative/`                | заглушка раздела                                     |

Расчёт можно отправить ссылкой: все параметры хранятся в адресной строке.

## Деплой

Боевой хостинг — domain.by (Apache, `.htaccess` в `public/`). Превью — GitHub Pages.
Шаги и настройка автодеплоя описаны в `TODO.md`.

Ручная выкладка:

```bash
npm run build
cd dist && zip -r ../amortize.zip . -x '.DS_Store' '*/.DS_Store'
```

Архив распаковать в корень сайта; точка после `-r` забирает и скрытый `.htaccess`.
