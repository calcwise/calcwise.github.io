# reference

Материалы для справки, в сборку не входят и линтером не проверяются.

- `cooperative-calculator.js` — черновик расчёта по программе кооператива (паи, членские и ежемесячные
  взносы). Пригодится при проектировании раздела «Кооператив».
- `standalone-v1/` — первая версия ипотечного калькулятора: одна HTML-страница и библиотека на big.js.
  Заменена приложением на Astro в `src/`; логика перенесена в `src/lib/mortgage/`.
